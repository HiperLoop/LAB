# Project structure overview

- video_data: contains raw video data of recorded particles.
- csv_data: contains video metadata and tracked particle trajectories from videos
- src: contains python scripts used for data analysis
- lab_jouranl: the lab journal for the experiment in both the python notebook and compiled pdf format with all relevant files and figures

## Note on running the code

Check that the input and output data paths are correct as the structure of the submission that we hand in might be different from how the project is structured on our end.
